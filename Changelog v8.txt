 Mimiron Hard Mode
--------------------



Everything is 100% fixed, The old DBM, timers only displayed when a spell was casted... Also the timers was incorrect,
So the Mimiron DBM was 100% Useless, Iv re-made the whole Mimiron LUA from scratch (Which took AGES), and its 100% accurate.

Frost bomb timers / Shock blast timers / Lazer barage timers, Everything is in, Everything is 100% Working. Enjoy!

Fixed Mimiron Normal mode - The previous versions was accurate for hard mode only, but now includes Easy mode.

Fixed the Plasma Blast timer - Now there is a timer "Plasma Cannon Chargin", after it finishes charing, the cannon will be able to fire.
Once the cannon starts firing there is a new timer "Plasma Blast Firing" - This is 3 second timer from the moment the cannon starts firing,
once the timer hits 0, the plasma blast starts coming out of the cannon and is hitting the tank.
